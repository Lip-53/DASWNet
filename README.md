# DASWNet

Dual-Axis Snake and Wavelet Fusion Network for RGB-Normal Aluminum Surface Defect Detection.

## Code availability

Code is not yet publicly available. Release updates will be posted in this repository.

## 项目说明

DASWNet 面向 RGB 图像与 Normal 法线图融合的铝材表面缺陷检测，包含 C3k_EDGblock 和 KWF-FPN。

当前仓库仅提供项目说明，代码尚未公开。发布进展将在此更新。
